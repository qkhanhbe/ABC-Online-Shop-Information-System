# abc_shop

Layered Python implementation of the ABC Online Shop information system (course essay, Chapter 5).

```
view <- controller -> service / ai -> dao -> model        (shop.py wires everything)
```

## Setup

```powershell
cd abc_shop
python -m pip install -r requirements.txt
```

Python 3.9+; only numpy and Pillow are needed at runtime, everything else is the standard library
(sqlite3, wsgiref, hashlib, hmac).

## Commands

| Command | What it does |
|---|---|
| `python main.py seed` | Create `data/abc_shop.db`: 16 products, 4 customers, 4 staff, one month of orders played through the services |
| `python main.py serve --port 8000` | Web application on http://localhost:8000 (seeds first if needed) |
| `python main.py demo` | End-to-end scenario printed step by step (in-memory database) |
| `python main.py search --text "black shoes"` | One search; also `--voice "..."`, `--image FILE`, or `--text` with `--image` |
| `python evaluate.py` | Evaluation of search, review insights and recommender |
| `python -m pytest -q` | 40 tests |
| `python tools/make_images.py` | Regenerate product and query images |

## Packages

| Package | Content | Use cases |
|---|---|---|
| `model/` | Customer, Product, Promotion, Cart, Order (state machine), Payment, StockLevel, InventoryEvent, Shipment, Review | - |
| `dao/` | `schema.sql`, `Database` (nested transactions), DAO interfaces, SQLite implementations, `VectorIndex`, `ImageStorage` | - |
| `service/` | Auth, catalogue, cart, checkout, payment, order, inventory, shipment, review, report; provider gateways | UC01-UC32 |
| `ai/` | `search/` (query, speech, image, search, ranking - from Assignment 06), `review_insights.py`, `recommender.py` | UC05, UC33, UC34 |
| `controller/` | WSGI router, request/response/session, five controllers | all screens |
| `view/` | HTML templates and stylesheet | - |
| `tests/` | model, checkout, operations, AI, web and architecture tests | - |

## Simulations

* Speech-to-text is simulated: the "audio" argument is the transcript a speech engine would return.
* The payment provider and the carrier are simulated behind `PaymentGateway` and `ShippingGateway`;
  provider results are HMAC-signed and verified as a real callback would be.
* Product images are synthetic drawings generated by `tools/make_images.py`.
